# บั๊กที่พบจากการทดสอบ (รอบ 20 ต.ค. 2569)

ที่มา: autotest E2E + ตรวจรูปหน้าจอด้วยตา (บทบาทผู้ทดสอบมือ)

| รหัส | ระดับ | เรื่อง | สถานะ |
|---|---|---|---|
| BUG-1 | ต่ำ | เลขเสื้อวิน/ลำดับที่ยาวเกิน 3 หลักล้นวงกลมสติกเกอร์ (เห็นในหน้าแชร์ทริป) | แก้แล้ว — `StopNumber` ย่อตัวอักษรตามจำนวนหลัก |
| BUG-2 | ต่ำ | หน้าจ่ายเงินของผู้โดยสารพูดเรื่องจ่ายเงินสดซ้ำสองบรรทัดเมื่อคนขับยังไม่ตั้งพร้อมเพย์ | แก้แล้ว — แสดงบรรทัดล่างเฉพาะตอนมี QR |
| BUG-3 | กลาง | หน้าโปรไฟล์คนขับ: กด "ยืนยันตัวตนคนขับ" ก่อนโปรไฟล์โหลดเสร็จ จะไปหน้าส่งเอกสารแทนหน้าสถานะที่ถูกต้อง (ยังแสดงเหตุผลที่ถูกปฏิเสธให้เห็นอยู่) | แก้แล้ว — ปิดแถวนี้จนกว่าโปรไฟล์โหลดเสร็จ |
| NOTE-1 | – | ตัวจำกัดล็อกอิน 20 ครั้ง/15 นาที/IP ทำให้ชุดทดสอบที่สมัครซ้ำหลายรอบถูกบล็อก | ปรับได้ด้วย `AUTH_RATE_LIMIT_MAX` (ใช้เฉพาะ stack ทดสอบ ห้ามตั้งบน production) |
| NOTE-2 | – | ข้อมูลทดสอบชน: เบอร์วินซ้ำในพื้นที่เดียวกันถูกปฏิเสธ (เป็นกฎของระบบที่ถูกต้อง) | เทสต์ใช้เบอร์วินไม่ซ้ำทุกรอบ |
