User Journey ผู้ใช้บริการ (มิ้นท์)

ขั้นตอนสิ่งที่ทำความรู้สึกจุดที่เสี่ยงKUVIN ตอบ
เปิดแอปและเรียกวินเลือกปลายทางหรือปักหมุด ดูค่าโดยสาร กดเรียกวิน🙂ไม่แน่ใจค่าโดยสารแสดงค่าโดยสารก่อนยืนยัน
รอคนขับดูสถานะและตำแหน่งคนขับที่กำลังมา แชตนัดจุดรับ😟ไม่รู้ว่าคนขับอยู่ไหน รอนานแผนที่และสถานะแบบทันที พร้อมแจ้งเตือนบนมือถือ
ขึ้นรถและเดินทางตรวจชื่อ ทะเบียน และหมายเลขวิน แล้วขึ้นรถ🙂กังวลความปลอดภัยโดยเฉพาะตอนค่ำปุ่ม SOS แชร์ลิงก์การเดินทาง ซ่อนเบอร์โทร
ถึงที่หมายและชำระเงินเลือกจ่ายเงินสดหรือโอนพร้อมเพย์ อัปโหลดสลิป🙂สลิปไม่ผ่านหรือมีข้อโต้แย้งเรื่องเงินตรวจสลิปอัตโนมัติ และเปิดข้อพิพาทได้
ให้คะแนนให้ดาว 1–5 และเขียนความคิดเห็น😀มีปัญหาแต่ไม่รู้จะแจ้งใครรายงานปัญหาถึงผู้ดูแลวิทยาเขต

User Journey ผู้ขับขี่ (ลุงสมชาย)

ขั้นตอนสิ่งที่ทำความรู้สึกจุดที่เสี่ยงKUVIN ตอบ
สมัครและยืนยันตัวตนอัปโหลดรูปถ่าย บัตร ใบขับขี่ รูปรถ แล้วรอผู้ดูแลอนุมัติ😟ไม่ถนัดอัปโหลดรูปหลายขั้นตอนแบ่งเป็น 2 ขั้น ปุ่มใหญ่ ข้อความสั้น
ออนไลน์เข้าคิวกดออนไลน์ รอถึงลำดับ🙂กลัวคิวไม่เป็นธรรมคิวเข้าก่อนได้ก่อน มีการล็อกกันงานซ้ำ
รับงานเห็นจุดรับ จุดส่ง ค่าโดยสาร ภายใน 15 วินาที กดรับหรือปฏิเสธ🙂เวลาตอบรับสั้น พลาดงานง่ายนับถอยหลังชัดเจน ไม่ตอบรับครบ 3 ครั้งจึงพักออฟไลน์
ส่งผู้โดยสารและรับเงินกดถึงจุดรับ เริ่มเดินทาง จบการเดินทาง และยืนยันรับเงิน🙂ลืมกดยืนยัน งานค้างปุ่มเดียวต่อสถานะ นำทางด้วยแผนที่
ดูรายได้ดูรายได้และบันทึกรายจ่าย รายวัน/สัปดาห์/เดือน😀จดตัวเลขไม่ครบหน้าการเงินสรุปให้อัตโนมัติ
