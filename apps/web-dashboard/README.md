# KU VIN Web Dashboard

React — สำหรับผู้ดูแลระบบ (Administrator)

> package.json นี้เป็นโครงร่างเบื้องต้น เมื่อจะเริ่มพัฒนาจริงให้รัน
> `npm create vite@latest . -- --template react` ในโฟลเดอร์นี้ (หรือ `npm install` ตรงนี้ได้เลยถ้าใช้ dependency ตามที่กำหนดไว้)

## โครงสร้าง

```
src/
├── pages/         # หน้าจัดการผู้ใช้งาน, ผู้ขับขี่, รายการคำขอใช้บริการ, รายงาน
├── components/    # UI component ใช้ร่วมกัน (ตาราง, การ์ด, ฟอร์ม)
├── services/      # api client
├── hooks/
└── App.jsx
```

## ฟังก์ชันหลักตาม Proposal

- จัดการข้อมูลผู้ใช้ / ผู้ขับขี่ (อนุมัติ-ปฏิเสธการยืนยันตัวตนคนขับ)
- ตรวจสอบรายการคำขอใช้บริการและประวัติการใช้บริการ
